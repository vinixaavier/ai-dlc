ai-dlc

Plataforma local de exploração de AI rodando em Kind e gerenciada com GitOps. Execute e observe AI CLIs, transforme explorações em agentes e conecte esses agentes a CLIs locais, chats, Kubernetes, eventos de cron, issues de repositórios e outros sistemas — com todo o fluxo traçado e mensurável.

Kind GitOps / Argo CD kagent / Go ADK AgentGateway (A2A · MCP · OpenAI) SGLang @ RTX 5090 OTel · Tempo · Prometheus · Loki · Grafana

01Arquitetura

Percurso de tracing: AgentGateway → kagent → Go ADK → AgentGateway (/v1/chat/completions) → SGLang. Os exporters in-cluster enviam para http://otel-collector.otel.svc.cluster.local:4317. O SGLang fica intencionalmente fora do Kind (GPU, NVIDIA device plumbing e DCGM no host).

02Componentes

Kind

Runtime Kubernetes local. Config declarativa em kind/kind-config.yaml. Nome-alvo do cluster: ai-dlc (atual: gitops-ai, intencionalmente não renomeado).

OCI Registry

Registry HTTP persistente dentro do cluster no namespace registry com PVC de 20Gi. Cada nó do Kind tem o containerd configurado para consumi-lo via HTTP. Argo CD e workloads usam o Service do Kubernetes.

kagent

Agentes com conhecimento de Kubernetes no runtime Go ADK (golang-adk:0.10.1-otel). O controller de substrate é construído da fonte v0.10.1 com o patch de tracing aplicado.

AgentGateway

Roteamento A2A, MCP e compatível com OpenAI. Exposto em aigw.localhost e NodePort 30081 (WSL / fora da rede do Kind).

AgentRegistry

Descoberta de agentes e MCPs. Seu catálogo não é um CRD — é sincronizado por um hook do Argo via API de catálogos.

kGateway

Implementação Gateway API responsável pelos gateways e rotas HTTP (argocd, grafana, analytics, etc.).

Observabilidade

OpenTelemetry Collector, Tempo (traces), Prometheus (métricas, incluindo o job substrate na porta 9090 dos pods de ate-system) e Loki (logs) — tudo visualizado no Grafana.

SGLang (RTX 5090)

Backend de modelos externo em 172.17.0.1:8000, gerido por Docker Compose em compose/sglang/. Lê compose/sglang/.env, com fallback para ../local-docker-vllm-rtx-5090/.env (override: SG_LANG_ENV_FILE; desligar: START_SGLANG=false).

04Bootstrap

# Em uma máquina nova com Docker, Kind, kubectl, Helm e as imagens custom prontas:
./scripts/bootstrap-kind-gitops.sh

O script é idempotente e executa, em ordem:

1 · cria Kind→ 2 · instala registry in-cluster→ 3 · configura containerd (HTTP)→ 4 · publica imagens & charts-pai→ 5 · instala Argo CD→ 6 · aplica applications→ 7 · Argo reconcilia
Imagens obrigatórias no registry local: kagent-dev/kagent/golang-adk:0.10.1-otel e kagent-dev/kagent/controller:0.10.1-otel — carregadas em todos os nós do Kind.
